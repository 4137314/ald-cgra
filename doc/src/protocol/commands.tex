\subsection{Command protocols}

The legacy protocol (Table~\ref{tab:proto}) uses one-byte commands whose
payload lengths follow from the geometry. Version~2 has six commands;
version~3 adds \cmd{EXEC}, which carries the step count, a flags byte (bit~0
clears the PE registers first), a 16-bit tap mask and the edge operands, and
returns only the selected registers with a checksum and a status byte
(Fig.~\ref{fig:exec}). Configuration and read-back use row-major indices
$rC+c$; an input payload holds all $R$ west words followed by all $C$ north
words. The identification reply reports version and geometry, so one host
binary drives either version and any supported geometry.
