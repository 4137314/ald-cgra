\section{Conclusion}
\label{sec:conclusion}

The project connects a configurable 16-bit mesh, a UART controller and a
reusable host API, with functional verification across eight device shapes.
The mapping analysis identifies distinct uses of PE resources: diagonal
computation, local MAC accumulation, product forwarding and host reduction.
A single result register limits simultaneous independent forwarding but does
not forbid local output-stationary accumulation.

Current v2/v3 experiments isolate protocol fusion while keeping mappings and
inputs fixed. They measure transactions and bytes after checking scalar
results; reductions in these quantities are not board timings or CPU speedups.
A Vivado 2026.1 run passes synthesis and routed setup/hold checks for the
default mesh at a 10 ns constraint. Other configurations, comparative area
and timing benefits, and physical board acceptance remain to be evaluated.

The next software improvement is implicit convolution tile generation to
avoid the dense Toeplitz workspace. Architectural experiments can compare
extra routing/storage resources and alternative schedules on matched
workloads. Burst commands or more than sixteen PEs require an explicit
protocol extension, buffering and stronger framing/recovery. These extensions
should preserve the independent kernel references and record both host and
device costs.
