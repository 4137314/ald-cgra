\subsection{Convolution and prefix scan}

Full convolution is expressed as a Toeplitz matrix--vector
product~\cite{golub-vanloan}. The host generates only tiles intersecting the
band: element $(i,j)$ is $h[i-j]$ for $0\leq i-j<k$, and zero otherwise.
For an input of length $n$ and an $R\times C$ tile, at most
$\lceil n/C\rceil(\lceil(k+C-1)/R\rceil+1)$ candidate tiles are visited.
Each costs $O(RC)$ host work; bounded tile storage replaces the dense
$(n+k-1)n$ workspace. Zero-weight and all-zero tiles still skip transfers.

Inclusive scan~\cite{blelloch} uses row~0. PE$(0,c)$ combines its west value
with the element on north input $c$; the previous block's last result enters
west input~0 as a carry. After $C$ steps all $C$ prefix results have settled.
The configuration is independent of the input values and is loaded once per
call. Supported folds are ADD, MUL, MIN and MAX, with 16-bit arithmetic.
