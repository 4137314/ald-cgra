\subsection{Wire cost}
\label{sec:cost}

Let $P=RC$, $E=R+C$ and $t$ the number of registers selected by a tap mask.
Table~\ref{tab:cost} gives request and reply sizes, including checksums. For
a $4\times4$ diagonal chunk, \cmd{WR}+\cmd{RUN}+\cmd{RD} costs 56 bytes in
three transactions, and \cmd{EXEC} with four taps 32 bytes in one.
Table~\ref{tab:kernel-counts} gives the resulting transaction counts of the
library kernels for nonempty inputs, a cached identity (the initial
identification, one transaction of six bytes, is excluded), no retries and
no skipped tiles; $K=\lceil n/L\rceil$, $Q=\lceil n/C\rceil$,
$T_R=\lceil M/R\rceil$ and $T_C=\lceil N/C\rceil$ for an $M\times N$ matrix.
With $B$ executed tile pairs in $C_a$ active column tiles, matrix--vector
and convolution need $C_a+(2R+2)B$ transactions in v2 and $C_a+RB$ in v3.
Every count reported in Section~\ref{sec:results} equals these closed forms;
the analysis scripts check this for every geometry before plotting.
