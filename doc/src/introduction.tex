\section{Introduction}
\label{sec:intro}

A coarse-grained reconfigurable array (CGRA) selects word-level operations and
communication paths at runtime~\cite{cgra-survey}. This project implements
such a fabric in VHDL and drives it from a host through a UART interface.
The default geometry is $4\times4$; the integrated controller, protocol and
host support positive $R\times C$ meshes with $RC\leq16$ and 16-bit data.
Reconfiguration changes the program, not the physical mesh dimensions.

The project provides four connected components:
\begin{itemize}
  \item a step-controlled mesh with one result register per PE and north/west
        edge injection;
  \item a versioned request/reply protocol with fused execution and an explicit
        contract for detected transfer failures;
  \item an installed C kernel API, emulator and declarative command-line tool;
  \item functional regression suites, a reproducible wire-cost experiment and
        scripts for a subsequent FPGA implementation campaign.
\end{itemize}

The report distinguishes local accumulation from independent operand
forwarding, counts computing and routing PEs separately, and includes host
reduction in the matrix algorithm. It reports current software byte/command
counts, not a speedup over a CPU. A real Vivado run verifies synthesis and routed timing for one default
configuration. Simulated enable spacing and the archived netlist reports
provide complementary evidence; physical board tests remain outstanding.
