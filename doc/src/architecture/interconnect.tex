Each PE reads the registered outputs of its four neighbours, so a value
advances at most one hop per step (Fig.~\ref{fig:array}). External operands
enter only at two edges: north input $c$ feeds PE$(0,c)$ and west input $r$
feeds PE$(r,0)$; the south and east borders read zero. All $RC$ registers
can be read back. Because a PE exposes one register to all four neighbours,
it cannot forward two independent operands in the same step. This
constrains schedules---it does not make output-stationary mappings
impossible (Section~\ref{sec:mappings})---and it is the reason why several
mappings below spend PEs on forwarding.
