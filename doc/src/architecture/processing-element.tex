\subsection{Processing element and mesh}

Each PE (Fig.~\ref{fig:pe}) has two 8-way operand multiplexers selecting a
neighbour's registered output (north, south, east, west), a 16-bit
immediate, its own register or zero; the eighth code is reserved and yields
zero. A 4-bit opcode selects one of sixteen operations: no-op, pass, add,
subtract, multiply and multiply--accumulate (low 16 bits of the product),
accumulate, bitwise AND/OR/XOR, logical left shift and arithmetic right
shift by the low four bits of the second operand, signed maximum, minimum
and absolute value, and constant load. Arithmetic wraps modulo $2^{16}$; in
particular $|{-32768}|=-32768$. A 32-bit configuration word holds the
immediate (bits 15--0), opcode (19--16) and selects (22--20, 25--23); bits
31--26 are unused. The single result register is the only state of a PE.
