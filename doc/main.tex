\begin{abstract}
This report presents the logical design of a coarse-grained reconfigurable
array (CGRA) implemented on an FPGA and driven from a host computer over a
serial link. The fabric is a $4\times4$ mesh of 16-bit processing elements
(PEs); the host reconfigures the array by loading one configuration word per
PE, injects operands at the array edges, advances the datapath a chosen number
of cycles and reads back the register file. A compact, checksum-protected UART
protocol connects a host-side software stack---a C library and a UNIX-style
command-line tool with a small configuration language---to the fabric. We
describe the PE datapath, the mesh interconnect, the control finite-state
machine, and the mapping of element-wise, reduction and weight-stationary
systolic dataflows onto the array under the architectural constraint of a
single register per PE with edge-only operand injection.
\end{abstract}
