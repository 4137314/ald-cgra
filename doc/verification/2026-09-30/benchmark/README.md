# CLI benchmarks and optional transport profiling — 30 September 2026

Implemented A10 on the public matvec/scan/conv APIs, independent scalar
references, one checked warm-up, retained API/CPU wall-time samples, median
and nearest-rank p95. Arbitrary custom mappings remain explicit skips; the
known custom ADD example is matched by structure, including its schedule.
Fixed the misleading built-in comment that claimed the ADD template squared
the sum; the implemented mapping has always performed addition only.

The schema-2 report embeds source hashes, actual compiler/build signatures,
platform and parameters. Optional `cgra_profile_t` preserves the existing
stats ABI and separates CFG read/write time from other transport time. These
intervals include serial waits or emulator work, and clock instrumentation
adds overhead. Remaining API wall time includes host computation/serialization.
Requested steps are logical request counts, not attested physical captures on
failure. Useful arithmetic counts describe the scalar dense formula (including
zero operands), excluding padding/routing and adding an initial zero; they
are not a count of the physical PE operations after data-dependent skipping.

The sweep executes each size once, preserves each complete report and its
hash, and publishes an index. Failed points and incomplete stdout/stderr stay
in the isolated run folder. If no report is produced, the old index survives.
The wrapper regression counts the actual CLI launches, rather than assuming
that loop structure implies no rerun.

## Geometry measurements

`measure_cli.py` executes and stores **40 actual points**: five shapes with
16 PEs, protocols v2/v3, add256, scan256, matvec16x16 and conv256/k5; one
warm-up and five measured repetitions per point. Every repetition is checked.
`geometry-points/manifest.json` contains the exact commands and artifact hashes;
each report contains source/build provenance and raw samples. All 40 PASS.
The benchmark edges-v2 dataset deliberately includes extremes and zero
weights. It differs from the review's positive-valued workload: for example,
matvec on 16x1 skips a zero-weight tile and transfers 11565 bytes per call.
The review's 12336-byte case was reproduced with its original input vectors
in `../../2026-09-28/geometry-before/`;
no value is forced to match a different workload.

Host/emulator timings are not FPGA throughput, area, timing or CPU speedup.
The 115200/8N1 line model can only estimate serialized link limits.
